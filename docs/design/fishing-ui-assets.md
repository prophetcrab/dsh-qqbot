# 钓鱼玩法：HTML 截图交互与美术素材

## 交互方式

QQ 中发送的是静态截图，不能点击 HTML。

```text
用户发送命令
→ DSH 处理游戏状态
→ DSH 渲染 HTML
→ headless browser 截图
→ Koishi 发送图片
```

HTML 只负责展示，所有操作仍然由 `/` 命令触发。

## 截图规格

```text
主画布    1080 × 1440
截图格式  PNG 或 WebP
设计比例  3:4 竖图
```

所有页面共用同一画布和边距，避免 QQ 群里图片尺寸跳动。

## 美术方向

```text
旧河夜钓 × 漫画手账
深青夜色、暖黄灯光、纸张米色、墨线边框
少量稀有度高光
```

不追求复杂动画，重点是可读性和统一性。

# CSS / SVG 资产方案

## 主背景

```text
深色线性渐变
中央暖色径向光
SVG 水波曲线
叠加低透明度噪点
```

建议色板：

```css
--night: #071417;
--river: #123843;
--ink: #0c1f25;
--lamp: #e8b56b;
--paper: #efe5cf;
--paper-dark: #d8c7a7;
```

## 纸张纹理

```text
米色渐变
低透明度 SVG feTurbulence 噪点
轻微暗角
```

不使用外部纹理图片，避免接缝和压缩失真。

## 十连卡背

```text
CSS 渐变底色
CSS 边框
SVG 鱼线稿或水波纹理
稀有度光效由 box-shadow / radial-gradient 叠加
```

## 边框与徽章

```text
边框用 border + box-shadow + 稀有度颜色
徽章用 CSS 圆角标签
进度条用 div + gradient
```

这样截图放大、缩放都不会模糊。

## 截图模板实现原则

```text
HTML 固定 1080×1440
CSS 负责布局和文字
图片只做背景、图标和装饰
不依赖外部字体
不依赖网络图片
不播放动画
```

之后实现时，先生成单张钓鱼结果页，再复用到鱼仓、十连和卡池页。
