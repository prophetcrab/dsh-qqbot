# 钓鱼玩法：HTML 截图交互与美术素材

## 交互方式

QQ 中发送的是静态截图，不能点击 HTML。

```text
用户发送命令
→ DSH 处理游戏状态
→ DSH 渲染 HTML
→ headless browser 截图
→ Koishi 发送图片
```

HTML 只负责展示，所有操作仍然由 `/` 命令触发。

## 截图规格

```text
主画布    1080 × 1440
截图格式  PNG 或 WebP
设计比例  3:4 竖图
```

所有页面共用同一画布和边距，避免 QQ 群里图片尺寸跳动。

## 美术方向

```text
旧河夜钓 × 漫画手账
深青夜色、暖黄灯光、纸张米色、墨线边框
少量稀有度高光
```

不追求复杂动画，重点是可读性和统一性。

# 图标规范

所有物品图标统一：

```text
方形画布
单个主体
居中
透明背景
正面或侧视
干净深色描边
有限色板
平面光照
无文字
无阴影
无场景
```

鱼竿图标：

```text
斜向放置完整鱼竿
不同等级用材质区分
Lv.1 竹/玻璃钢
Lv.2 碳素
Lv.3 高碳素
Legendary 加入金/旧木/纹饰
```

鱼饵图标：

```text
普通鱼饵做成小饵团/虫饵
传奇鱼饵致敬现实经典拟饵外形
不画鱼
```

特殊物品图标：

```text

不做鱼形

```

货币图标：

```text
金币：暖金色圆币
钓鱼币：鱼钩/鳞片造型的冷色代币
```

## 截图模板实现原则

```text
HTML 固定 1080×1440
CSS 负责布局和文字
图片只做背景、图标和装饰
不依赖外部字体
不依赖网络图片
不播放动画
```

之后实现时，先生成单张钓鱼结果页，再复用到鱼仓、十连和卡池页。
