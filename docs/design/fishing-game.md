## 鱼类计价

鱼按重量和单价共同计价。

同一种鱼，重量越大，`pricePerKg` 也越高。

### 单价随重量上浮

每条鱼有：

```text
basePricePerKg
weightKg 范围
weightPriceBonus
```

先计算该条鱼在鱼种重量区间中的位置：

```text
ratio = clamp((weightKg - minKg) / (maxKg - minKg), 0, 1)
```

再计算单价：

```text
pricePerKg = round(basePricePerKg * (1 + ratio * weightPriceBonus))
value = round(weightKg * pricePerKg)
```

`ratio = 0` 时使用基础单价，`ratio = 1` 时使用该鱼种的最大单价。

## 双货币

每个群的玩家钱包有两个余额：

```text
金币      平台通用货币，签到等玩法产出
钓鱼币    钓鱼玩法货币，卖鱼和特殊物品产出
```

固定汇率：

```text
10 钓鱼币 = 1 金币
```

双向自由兑换，无手续费。

兑换命令：

```text
/兑换钓鱼币 数量        用对应数量的金币兑换钓鱼币
/钓鱼 兑换金币 数量     用对应数量的钓鱼币兑换金币
```

钓鱼币换金币时：

```text
数量不足 10 或不是整十
按可兑换的最大数量向下取整
```

例如：

```text
有 25 钓鱼币，执行 /钓鱼 兑换金币 25
→ 消耗 20 钓鱼币，获得 2 金币，剩 5 钓鱼币

有 17 钓鱼币，执行 /钓鱼 兑换金币 25
→ 消耗 10 钓鱼币，获得 1 金币，剩 7 钓鱼币
```

钓鱼类命令约定：

```text
/钓鱼 命令 参数
```

例外：`/兑换钓鱼币` 是顶级兑换入口。

规则：

```text
数量必须是正整数
钓鱼币换金币时，钓鱼币数量必须是 10 的倍数
余额不能为负数
同一次兑换写入两条钱包流水
兑换操作必须幂等
```

钱包结构：

```text
wallet.gold
wallet.fishingCoins
```

所有兑换、卖鱼、签到、商店扣款都通过 Wallet 统一入账，不直接修改玩家字段。

### 计价

鱼竿不改变鱼的单价：

```text

```text

### Lv.1–Lv.3 普通鱼饵

普通鱼饵不直接给固定概率，而是对当前鱼竿的概率组做乘算修正。

```text
raw[tier] = rodWeight[tier] * baitCoefficient[tier]
total = sum(raw)
probability[tier] = raw[tier] / total
```

最终五个等级的概率必须归一化到总和 100%。

系数小于 1 表示降低该等级权重，大于 1 表示提高。

没有装备鱼竿时，使用默认鱼类权重作为基础权重。

每级 3 种，共 9 种。

### 基础概率

单抽基础概率按鱼竿 10%、鱼饵 90% 分配。

```text
鱼饵 Lv.1      37.5%
鱼饵 Lv.2      30%
鱼饵 Lv.3      20%

```

合计 100%。

鱼竿整体 10%，鱼饵整体 90%。

同稀有度有多个物品时，在稀有度内部平均分配。

60 抽传奇鱼饵保底从五种传奇鱼饵中抽取。

### 保底

每个玩家在每个群独立记录保底进度。

```text
每 10 抽    保底一个 Lv.1 或 Lv.2 鱼竿
每 60 抽    保底一个传奇鱼饵
每 50 抽    保底一个 Lv.3 鱼竿
每 150 抽   保底一个传奇鱼竿
```

保底计数：

```text
rodPity
legendaryBaitPity
lv3RodPity
legendaryRodPity
```

四个计数每次抽卡都增加，互相独立。

### 保底触发与重置

同一抽只出一个物品。

多重保底同时到期时，优先级：

```text
传奇鱼竿 > Lv.3 鱼竿 > 传奇鱼饵 > Lv.1/Lv.2 鱼竿
```

触发后只重置触发的那一类保底：

```text
Lv.1/Lv.2 鱼竿 重置 rodPity
Lv.3 鱼竿       重置 lv3RodPity
传奇鱼竿        重置 legendaryRodPity
传奇鱼饵        重置 legendaryBaitPity
```

未触发的其他保底计数保留，可以下一抽继续触发。

自然抽中会按抽到的物品重置对应保底：

```text
任意鱼竿       重置 rodPity
Lv.3 或传奇鱼竿 重置 lv3RodPity
传奇鱼竿       重置 legendaryRodPity
传奇鱼饵       重置 legendaryBaitPity
```

保底触发时只重置触发的那一类。

10 抽保底的鱼竿只从 Lv.1 和 Lv.2 鱼竿中抽取，按这两级的基础权重重新归一化。

### 抽卡记录

`/钓鱼 抽卡记录` 展示最近 50 抽：

```text
时间
抽数
物品
等级/类型
是否保底触发
重复鱼竿回收金额
```

抽卡记录属于 fishing 插件，不写入账号背包。

### 十连

十连是十次独立抽卡，按顺序逐次计算保底。

```text
/钓鱼 单抽    单抽
/钓鱼 十连    十连
```

### 重复鱼竿

玩家已经拥有的鱼竿再次抽到时，不进入鱼竿库，按该鱼竿的售价自动出售为钓鱼币。

回收价格使用“鱼竿出售价格”表中的单把售价，不再按等级固定。

回收写入 Wallet 流水：

```text
reason: duplicate_rod_sale
```

鱼饵重复时正常堆叠数量。

抽卡扣款、物品发放、重复回收和保底更新必须在同一个事务中完成。

## 抽卡券

钓鱼模块有两种抽卡道具：

```text
钓鱼单抽券
钓鱼十连券
```

规则：

```text
抽卡券是钓鱼模块专属消耗品
不是货币
不能出售
不能兑换成钓鱼币
不进入鱼仓

存放在钓鱼道具库的抽卡券栏：

```text
equipment.tickets:
  singleTickets
  tenTickets
```

### 使用规则

```text
/钓鱼 单抽
  优先消耗 1 张钓鱼单抽券
  没有券时消耗 10 钓鱼币

/钓鱼 十连
  优先消耗 1 张钓鱼十连券
  没有券时消耗 90 钓鱼币
```

两种券不混用：

```text
单抽券只能用于单抽
十连券只能用于十连
```

抽卡券抽卡同样累计保底进度。

抽卡扣券、发放物品、重复鱼竿回收和保底更新必须在同一个事务中完成。

获取方式：

```text
钓鱼特殊物品掉落
其他活动/奖励待定
```

## 存放位置

`账号背包` 属于共享账号模块，不属于钓鱼插件。

以下属于 fishing 游戏插件：

```text
鱼仓
钓鱼道具库
钓鱼币
抽卡/保底状态
钓鱼进度
```

金币属于共享账号模块。

### 鱼仓

鱼仓只存放鱼，不存放鱼竿、鱼饵和特殊物品。

每条鱼是独立实例：

```text
instanceId
fishId
name
tier
weightKg
basePricePerKg
pricePerKg
value
caughtAt
```

鱼进入鱼仓后不会自动出售。

鱼的估值在钓到时结算，写入该条鱼的 `pricePerKg` 和 `value`；后续换鱼竿不改变已入仓鱼的价值。

### 钓鱼道具库

钓鱼道具库属于 fishing 插件，分为鱼竿、鱼饵和抽卡券：

```text
rods:
  ownedRodIds
  equippedRodId

baits:
  counts
  selectedBaitId

tickets:
  singleTickets
  tenTickets
```

规则：

```text
鱼竿按 ID 唯一持有，装备一根
鱼饵按数量堆叠，选择一种
抽卡券按数量堆叠
重复鱼竿在抽卡时自动出售，不进入钓鱼道具库
鱼饵使用后数量减一
抽卡券使用后数量减一
```

### 账号背包

`/账号背包` 只属于共享账号模块，只展示账号级资产：

```text
金币
账号级物品
```

不展示：

```text
鱼仓
钓鱼道具库
钓鱼币
钓鱼状态
```

鱼类明细使用 `/鱼仓`，鱼竿、鱼饵和抽卡券明细使用 `/钓鱼 道具库`。

### 特殊物品

特殊物品不进入鱼仓。

其中：

```text
抽卡券       进入钓鱼道具库
杂物 / 奇物   存放位置待定
```

## 特殊品类

独立于五个鱼类等级。

```text
category: special
tier: null
```

包含三类：

```text
极低价值杂物   固定价格
极高价值奇物   固定价格
抽卡券         不计价、不可出售
```

### 杂物与奇物

数据结构：

```json
{
  "kind": "special",
  "itemId": "example",
  "name": "示例物品",
  "fixedPrice": 0
}
```

展示格式：

```text
物品名 · 固定价格
```

### 抽卡券

钓鱼时可能钓到的特殊物品：

```text
钓鱼单抽券
钓鱼十连券
```

```json
{
  "kind": "ticket",
  "itemId": "single_ticket",
  "name": "钓鱼单抽券",
  "ticketType": "single",
  "count": 1
}
```

规则：

```text
不是鱼
不参与等级
没有固定价格
不能出售
进入钓鱼道具库
