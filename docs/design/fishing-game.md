# 二、货币与兑换

每个群的玩家钱包有两个余额：

```text
金币      平台通用货币，签到等产出
钓鱼币    钓鱼玩法货币，卖鱼和特殊物品产出
```

固定汇率：

```text
10 钓鱼币 = 1 金币
```

双向兑换，无手续费。

## 兑换命令

```text
/兑换钓鱼币 数量        金币换钓鱼币
/钓鱼 兑换金币 数量     钓鱼币换金币
```

规则：

```text
数量必须是正整数
金币换钓鱼币时，金币不足则拒绝
钓鱼币换金币时，按可兑换的最大数量向下取整
实际消耗的钓鱼币数量一定是 10 的倍数
余额不能为负
一次兑换写入两条钱包流水
兑换必须幂等
```

示例：

```text
有 25 钓鱼币，/钓鱼 兑换金币 25
→ 消耗 20 钓鱼币，获得 2 金币，剩 5

有 17 钓鱼币，/钓鱼 兑换金币 25
→ 消耗 10 钓鱼币，获得 1 金币，剩 7
```

钱包结构：

```text
wallet.gold
wallet.fishingCoins
```

所有金币和钓鱼币变动都通过 Wallet 入账。

# 四、鱼类计价

鱼按重量和单价共同计价。

同一种鱼，重量越大，`pricePerKg` 越高，最终价值同时受到重量和单价放大。

## 公式

```text
ratio = clamp((weightKg - minKg) / (maxKg - minKg), 0, 1)

pricePerKg = round(
  basePricePerKg * (1 + ratio * weightPriceBonus)
)

value = round(weightKg * pricePerKg)
```


等级鱼竿只有鱼稀有度概率组，没有特殊效果。

传奇鱼竿拥有概率组和致敬特殊效果。

## 概率组

装备鱼竿后，概率组由两部分组成：

```text
五档鱼稀有度权重
specialRate 特殊物品概率
```

先判定 specialRate：

```text
触发特殊物品 → 从特殊物品池抽取
未触发 → 用鱼档权重抽鱼
```

鱼档权重依次对应：

```text
Lv.1 鱼 / Lv.2 鱼 / Lv.3 鱼 / Lv.4 鱼 / Lv.5 鱼
```

鱼档权重是**未触发特殊物品时的条件权重**，五档合计 100。

最终整体概率：

```text
P(特殊物品) = specialRate
P(鱼 i) = (1 - specialRate) * fishWeight[i] / sum(fishWeight)
```

五档鱼概率与特殊物品概率合计：

```text
specialRate + (1 - specialRate) * 100% = 100%
```

鱼档权重不会被 specialRate 再次压缩。

# 六、鱼饵

鱼饵是消耗品，只在本次钓鱼生效。

玩家同一时间选择一种鱼饵。

鱼竿负责持久概率组，鱼饵负责单次修正。

## 普通鱼饵

Lv.1–Lv.3 每级 3 种，共 9 种。

普通鱼饵只修正五档鱼权重，不修正 specialRate。

```text
raw[tier] = rodWeight[tier] * baitCoefficient[tier]
total = sum(raw)
probability[tier] = raw[tier] / total
```

归一化只在鱼档内部进行，最终五档鱼概率合计 100%。

specialRate 保持鱼竿上的原值不变。

抽卡顺序：

```text
1. 先按 specialRate 判定特殊物品
2. 未触发时，再用修正后的五档鱼权重抽鱼
```

鱼饵只改变「未触发特殊物品时」的五档鱼条件分布：

```text
P(特殊物品) = rod.specialRate
P(鱼 i) = (1 - rod.specialRate) * baitAdjustedWeight[i]
```

所以鱼饵不会改变特殊物品的总概率，整体仍然归一化到 100%。

# 七、抽卡券

两种钓鱼模块消耗品：

```text
钓鱼单抽券
钓鱼十连券
```

规则：

```text
不是货币
不能出售
不能兑换钓鱼币
不进入鱼仓
进入钓鱼道具库
使用后数量减一
```

使用优先级：

```text
/钓鱼 抽卡
  1. 1 张单抽券
  2. 10 钓鱼币

/钓鱼 十连
  1. 1 张十连券
  2. 单抽券补次数
  3. 剩余次数用钓鱼币补齐
```

十连券不能用于单抽。

单抽券可以用于十连。

资源不足以覆盖整次抽卡时，直接失败，不扣资源。

用券抽卡同样累计保底。

获取方式：

```text
钓鱼特殊物品掉落
其他活动/奖励待定
```

传奇鱼饵内部：

```text
拉帕拉原版浮水米诺 50%
其余四种传奇鱼饵均分另外 50%
```

150 抽传奇鱼竿保底和 60 抽传奇鱼饵保底也使用该 UP 权重。

UP 物品的单个基础出率：

```text
太公竿       0.1785%
拉帕拉原版浮水米诺 1.25%
```

其他传奇鱼竿单个出率：

```text
0.0446%
```

其他传奇鱼饵单个出率：

```text
0.3125%
```

同稀有度非传奇物品在稀有度内部平均分配。

## 保底

每个玩家在每个群独立记录保底。

```text
每 10 抽    保底一个 Lv.1 或 Lv.2 鱼竿
每 50 抽    保底一个 Lv.3 鱼竿
每 60 抽    保底一个传奇鱼饵
每 150 抽   保底一个传奇鱼竿
```

计数：

```text
rodPity
lv3RodPity
legendaryBaitPity
legendaryRodPity
```

四项每次抽卡都增加，互相独立。

## 优先级

同一抽只出一个物品。

```text
传奇鱼竿 > Lv.3 鱼竿 > 传奇鱼饵 > Lv.1/Lv.2 鱼竿
```

未触发的其他保底保留，可以下一抽继续触发。

## 重置

保底触发时只重置触发的那一类。

自然抽中按物品重置对应保底：

```text
任意鱼竿       重置 rodPity
Lv.3 或传奇鱼竿 重置 lv3RodPity
传奇鱼竿       重置 legendaryRodPity
传奇鱼饵       重置 legendaryBaitPity
```

10 抽保底只从 Lv.1/Lv.2 鱼竿中抽取，按这两级基础权重重新归一化。

## 玩家级串行

同一名玩家的抽卡和十连必须串行。

```text
抽卡开始
→ 占用该玩家的抽卡锁
→ 扣款/扣券、抽卡、写保底、生成图片
→ 释放锁
```

锁持有到图片生成完成。

锁被占用时，再次抽卡直接回复：

```text
正在抽卡，请稍等待。
```

不进入队列，不扣资源。

## 结果图

`/钓鱼 抽卡` 和 `/钓鱼 十连` 优先返回程序化生成的 1080×1440 PNG 结果图。

```text
SVG 结果卡 → sips 转 PNG → Koishi 发送图片
```

图片渲染失败时回退文字结果。

## 十连

十连是十次独立抽卡，按顺序逐次计算保底。

## 重复鱼竿

已经拥有的鱼竿再次抽到时，按该鱼竿售价自动出售为钓鱼币。

回收写入钱包流水：

```text
reason: duplicate_rod_sale
```

鱼饵重复时正常堆叠。

扣款/扣券、发奖、重复回收、保底更新必须在同一事务中完成。

# 九、存放与归属

## 账号背包

属于共享账号模块，只展示账号级资产：

```text
金币
账号级物品
```

不展示鱼仓、钓鱼道具库、钓鱼币或钓鱼状态。

## 鱼仓

属于 fishing 插件，只存放鱼。

每条鱼独立保存：

```text
id             纯数字编号
fishId
name
tier
weightKg
basePricePerKg
pricePerKg
value
caughtAt
```

编号按玩家、按群递增。

鱼进入鱼仓后不会自动出售。

估值在钓到时结算，后续换鱼竿不改变已入仓鱼的价值。

卖鱼：

```text
/钓鱼 鱼仓
/钓鱼 卖鱼 编号
```

规则：

```text
编号必须是纯数字
只能出售鱼仓中存在的编号
出售后移除该条鱼，并增加对应 value 的钓鱼币
```

## 钓鱼道具库

属于 fishing 插件，存放鱼竿、鱼饵和抽卡券：

```text
rods:
  ownedRodIds
  equippedRodId

baits:
  counts
  selectedBaitId

tickets:
  singleTickets
  tenTickets
```

规则：

```text
鱼竿按 ID 唯一持有，装备一根
鱼饵按数量堆叠，选择一种
抽卡券按数量堆叠
重复鱼竿抽卡时自动出售
鱼饵和抽卡券使用后数量减一
```

展示为一张纵向长图，高度随鱼竿/鱼饵数量增长。


## 特殊物品

特殊物品不进入鱼仓。

```text
抽卡券       进入钓鱼道具库
杂物 / 奇物   存放位置待定
```

## 插件边界

```text
共享账号模块    账号背包、金币
fishing 插件    鱼仓、钓鱼道具库、钓鱼币、抽卡/保底、钓鱼状态
Koishi 插件     命令入口，不持久化游戏资产
```

每个小游戏在 DSH 和 Koishi 各有一个插件。

# 十、特殊物品

特殊物品独立于五个鱼类等级。

```text
category: special
tier: null
```

按价值层级分两类：

```text
低价值杂物       固定价格
高价值特殊物品
  ├─ 高价值奇物   固定价格
  └─ 抽卡券       不计价、不可出售
```

特殊物品内部权重：

```text
低价值杂物   70%
高价值特殊物品 30%
```

组内均分：

```text
低价值 6 种，每种 11.6667%
高价值 7 种（5 奇物 + 2 抽卡券），每种 4.2857%
```

特殊物品整体概率为单次钓鱼 3%，绝对概率：

```text
低价值杂物：每种 0.35%
高价值物品：每种 0.1286%
```
