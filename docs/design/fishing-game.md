## 鱼类计价

鱼按重量计价，不按条固定价格。

```text
value = round(weightKg * pricePerKg)
```

每条鱼获需要保存：

```text
kind
fishId
name
tier
weightKg
pricePerKg
value
```

展示格式：

```text
鱼名 + 重量 + pricePerKg 钓鱼币/kg + 本次估值
```

价格单位统一为：

```text
钓鱼币/kg
```

钓鱼产出的鱼和特殊物品进入本群玩家背包，卖出后获得钓鱼币。

## 双货币

每个群的玩家钱包有两个余额：

```text
金币      平台通用货币，签到等玩法产出
钓鱼币    钓鱼玩法货币，卖鱼和特殊物品产出
```

固定汇率：

```text
10 钓鱼币 = 1 金币
```

双向自由兑换，无手续费。

兑换命令：

```text
/兑换 金币 1      消耗 10 钓鱼币，获得 1 金币
/兑换 钓鱼币 10   消耗 1 金币，获得 10 钓鱼币
```

规则：

```text
数量必须是正整数
钓鱼币换金币时，钓鱼币数量必须是 10 的倍数
余额不能为负数
同一次兑换写入两条钱包流水
兑换操作必须幂等
```

钱包结构：

```text
wallet.gold
wallet.fishingCoins
```

所有兑换、卖鱼、签到、商店扣款都通过 Wallet 统一入账，不直接修改玩家字段。

## 鱼竿

鱼竿分三个等级，共九把；另有五把传奇鱼竿。

```text
Lv.1    3 把
Lv.2    3 把
Lv.3    3 把
Legendary 5 把
```

每根鱼竿有两类独立属性：

```text
fishingEffect     钓鱼效果
pricePerKgBonus   单价属性，单位：钓鱼币/kg
```

鱼竿的单价属性作用在鱼的单价上：

```text
effectivePricePerKg = fish.pricePerKg + equippedRod.pricePerKgBonus
value = round(weightKg * effectivePricePerKg)
```

特殊物品是固定价格，不受鱼竿单价属性影响。

玩家同一时间只装备一根鱼竿。

## 鱼饵

鱼饵稀有度与鱼竿对应：

```text
Lv.1
Lv.2
Lv.3
Legendary
```

鱼饵是消耗品，只在本次钓鱼生效，使用后数量减一。

玩家同一时间选择一种鱼饵。

```text
selectedBait
baitInventory
```

鱼饵与鱼竿的职责区分：

```text
鱼竿    持久装备，影响钓鱼效果和鱼的 pricePerKg
鱼饵    单次消耗，影响本次钓鱼结果
```

默认鱼饵不带 pricePerKg 加成。

传奇鱼饵额外带有一个只作用于本次钓鱼的特殊效果；具体效果待定。

鱼饵名称、钓鱼效果、获取方式、购买价格和消耗规则待定。

## 抽卡池

鱼饵和鱼竿混池。

### 消耗

```text
单抽      10 钓鱼币
十连      90 钓鱼币
```

### 基础概率

单抽基础概率：

```text
鱼饵 Lv.1      30%
鱼饵 Lv.2      24%
鱼饵 Lv.3      16%
传奇鱼饵        2%
鱼竿 Lv.1      14%
鱼竿 Lv.2       8%
鱼竿 Lv.3       5%
传奇鱼竿        1%
```

合计 100%。

同稀有度有多个物品时，在稀有度内部平均分配。

### 保底

每个玩家在每个群独立记录保底进度。

```text
每 10 抽    保底一个鱼竿
每 30 抽    保底一个传奇鱼饵
每 50 抽    保底一个 Lv.3 鱼竿
每 100 抽   保底一个传奇鱼竿
```

保底计数：

```text
rodPity
legendaryBaitPity
lv3RodPity
legendaryRodPity
```

四个计数每次抽卡都增加，互相独立。

### 保底触发与重置

同一抽只出一个物品。

多重保底同时到期时，优先级：

```text
传奇鱼竿 > Lv.3 鱼竿 > 传奇鱼饵 > 任意鱼竿
```

触发后只重置触发的那一类保底：

```text
任意鱼竿       重置 rodPity
Lv.3 鱼竿      重置 lv3RodPity
传奇鱼竿       重置 legendaryRodPity
传奇鱼饵       重置 legendaryBaitPity
```

未触发的其他保底计数保留，可以下一抽继续触发。

自然抽中不重置任何保底计数。

### 十连

十连是十次独立抽卡，按顺序逐次计算保底。

```text
/抽卡         单抽
/抽卡 10      十连
```

### 重复鱼竿

玩家已经拥有的鱼竿再次抽到时，不进入鱼竿库，自动出售为钓鱼币。

回收价：

```text
Lv.1 鱼竿       20 钓鱼币
Lv.2 鱼竿       50 钓鱼币
Lv.3 鱼竿      150 钓鱼币
传奇鱼竿        600 钓鱼币
```

回收写入 Wallet 流水：

```text
reason: duplicate_rod_sale
```

鱼饵重复时正常堆叠数量。

抽卡扣款、物品发放、重复回收和保底更新必须在同一个事务中完成。

## 存放位置

玩家钓鱼相关资产分为三个独立区域：

```text
鱼仓      钓到的鱼
装备库    鱼竿和鱼饵
钱包      金币和钓鱼币
```

### 鱼仓

鱼仓只存放鱼，不存放鱼竿、鱼饵和特殊物品。

每条鱼是独立实例：

```text
instanceId
fishId
name
tier
weightKg
pricePerKg
value
caughtAt
```

鱼进入鱼仓后不会自动出售。

鱼竿的单价加成在钓到鱼时结算，写入该条鱼的 `pricePerKg` 和 `value`；后续换鱼竿不改变已入仓鱼的价值。

### 装备库

装备库分为鱼竿和鱼饵：

```text
rods:
  ownedRodIds
  equippedRodId

baits:
  counts
  selectedBaitId
```

规则：

```text
鱼竿按 ID 唯一持有，装备一根
鱼饵按数量堆叠，选择一种
重复鱼竿在抽卡时自动出售，不进入装备库
鱼饵使用后数量减一
```

### 账号背包

`/账号背包` 保留为总览：

```text
金币
钓鱼币
鱼仓数量
装备库概览
```

鱼类明细使用 `/鱼仓`，鱼竿和鱼饵明细使用 `/装备库`。

### 特殊物品

特殊物品不进入鱼仓，也不进入装备库。

具体存放位置待定。

## 特殊品类

独立于五个鱼类等级。

```text
category: special
tier: null
priceType: fixed
```

规则：

```text
不是鱼
不参与等级
按固定价格计价
包含极低价值和极高价值两类
```

数据结构：

```json
{
  "kind": "special",
  "itemId": "example",
  "name": "示例物品",
  "fixedPrice": 0
}
```

展示格式：

```text
物品名 · 固定价格
```

具体特殊物品名称和价格待定。
