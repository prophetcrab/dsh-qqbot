# dsh-qqbot v0.7.0 (Windows x64)

Windows x64 release (Docker-backed NapCat, Linux QQ in a container).

## Highlights

- 首个 Windows x64 发布：NapCat/Linux QQ 运行在 Docker 容器中，Koishi 运行在宿主机，不再依赖本机 QQ 或管理员授权。
- 新增 Windows 平台层与 Docker 后端：自动探测/拉起 Docker Desktop、生成 compose、管理容器和 OneBot 反向 WS。
- 支持 NapCat 容器与 Koishi 的生命周期跟随 DSH：DSH 退出时自动停止 Koishi 和容器，Docker Engine 保持运行。
- 新增 **Token 使用统计**：总体、今日、按群、最近 100 次发言、缓存命中率，持久化并支持手动清空。
- 扩展 ReAct 工具集：`web_search`、`weather`、`group_search`、`read_url`、`market_quote`、`calculator`、`finance_calendar`。
- 工具选择改为目标驱动：模型自行判断是否需要工具、使用哪个工具、是否需要继续，不再按关键词强制调用。
- 支持多种 tool call 格式，包括同一轮多个工具调用。
- 新增群历史消息归档检索 `group_search`，检索范围限定当前群。
- 新增实时数据工具：天气、行情、财经日历、网页正文读取。
- 最近记忆保留上限从 100 调整为 50，并继续带群标签，避免跨群记忆混淆。
- 功能面板改为只读状态页，移除启停和安装配置卡片，并移动到最后一个 Tab。

## Windows Branch Changes

- 拆分 macOS/Windows 平台层，`dshbot-win64` 只保留 Windows 平台实现和 Windows 资源。
- 移除 macOS 本地 NapCat 后端、离线 payload 和 darwin 运行时依赖包。
- Windows 默认 NapCat 后端固定为 Docker，`host/platform/win` 负责路径、进程、端口和 npm 调用。
- 新增 Windows 离线 Koishi 依赖包：`template/runtime-bundles/node_modules-win32-x64.tar.gz`。
- CI 改为 Windows runner，不再依赖 macOS runner 和 librsvg。
- 文档改为 Windows/Docker 安装与接入说明；`main` 后续只保留导向与发布管理。

## Fixes

- 修复 NapCat OneBot 配置中同时存在多个反向 WS 客户端导致的重复命令回复。
- 修复模型输出已带 `@` 时客户端再次添加结构化 `<at>` 造成的重复 @。
- 修复 Docker 后端首次启动时的镜像拉取、容器启动和登录等待。
- 修复 Koishi 自定义端口未同步到 `koishi.yml` 导致面板请求 `fetch failed`。
- 修复 Koishi 停止后 worker/supervisor 自动重启、遗留端口占用和旧 PID 无法重启的问题。
- 修复 DSH 退出后 NapCat 容器被 Docker restart policy 重新拉起的问题。
- 修复 GitHub CI 在 Linux/macOS 环境下 SVG 卡片渲染失败；Windows 改用内置 `@resvg/resvg-js`。
- 修复 Token usage 二次归一化后统计为 0 的问题。
- 修复模型输出 `<toolcall>` 格式时工具调用未被识别的问题。
- 行情工具增加多数据源回退与更稳健的字段解析。

## Tool Notes

- `group_search` 检索的是进入 group-loop 的消息归档，不是 QQ 全量聊天记录。
- `weather` 使用 Open-Meteo；`finance_calendar` 使用东方财富；`market_quote` 使用腾讯/新浪行情。
- 行情工具只提供只读快照，不做交易建议。
- 实时工具需要网络连接。

## Requirements

- Windows 10/11 x64
- Docker Desktop + WSL2
- DSH `>=0.2.1-rc.2 <0.3.0`
- Node.js `^22.19.0 || >=24.0.0`
- 首次安装需要能访问 Docker Hub，或预先导入 `mlikiowa/napcat-docker:latest`
- 首次登录需要手机 QQ 扫描 NapCat 二维码

## Validation

- 291 DSH tests
- 67 qq-bot tests
- Client build, host smoke, client smoke, architecture guard
- Windows CI workflow configured

## Upgrade Notes

- 这是 Windows 分支首个 v0.7.0 发布，与 macOS v0.7.0 分别发布，版本号相同、资产不同。
- 安装后在「概览」点击「一键安装并配置」；流程会创建 Koishi 项目、解压 Windows 离线依赖、拉取 NapCat 镜像并启动容器。
- 如果扫码超过 30 秒，需要在面板再点一次「写入 OneBot 配置」完成反向 WS 配置。
- 现有玩家、金币、角色和群状态数据格式兼容；Docker 数据目录中的 QQ 登录态会随容器重建保留。
- 不要同时运行本机 NapCat/QQ 和容器内 NapCat 的同一个 QQ 账号。
