# dsh-qqbot v0.7.7 (macOS Apple Silicon)

## Release-only changes

- 重新打包 v0.7.6 的插件代码，发布在 CI 已修复的提交上。
- CI 不再调用已删除的 `offline:verify`，改为检查内置 Koishi 运行时包和 `npm pack` 内容。
- 包含 v0.7.6 的首次安装修复：NapCat 先创建 `data/`、`runtime/` 时，Koishi 项目会在原目录补全，不再报 `project-not-empty` / `missing package.json`。

## Requirements

- macOS Apple Silicon only
- DSH `>=0.2.1-rc.2 <0.3.0`
- Node.js `^22.19.0 || >=24.0.0`
- OrbStack 已安装并完成首次初始化
- 可访问 GitHub Release（首次启动下载约 594 MB 的 NapCat 镜像包）
- 首次使用手机扫码登录机器人 QQ
