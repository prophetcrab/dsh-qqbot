# dsh-qqbot v0.7.6 (macOS Apple Silicon)

## Fixes

- **首次安装不再被 NapCat runtime 目录卡住**：如果 NapCat Docker 在 Koishi scaffold 之前创建了 `<projectDir>/data` 或 `<projectDir>/runtime`，`ensureProject` 现在会把这种仅包含插件自有运行目录的目录补全成 Koishi 项目，而不是报 `project-not-empty`。
- 修复插件市场安装后点击「启动 Koishi」可能出现的：

```text
Koishi 项目缺少 package.json：/Users/crab/project/qq-bot
```

`data/` 和 `runtime/` 会保留，不会因为补全项目而丢失。
