# dsh-qqbot v0.7.5 (macOS Apple Silicon)

## Highlights

- **NapCat 改为 Docker / OrbStack 后端**：不再修改或注入本机 `/Applications/QQ.app`，不需要 macOS 管理员授权；QQ 客户端可以继续正常使用。
- **NapCat 镜像从 GitHub Release 安装**：首次启动时自动下载 `napcat-docker-latest.tar.gz`，校验 SHA-256 后执行 `docker load`，不再依赖 Docker Hub 拉取。
- **GitHub 环境重装**：从 `prophetcrab/dsh-qqbot@dshbot-mac` 拉取定制 Koishi 模板，同步代码、安装依赖、准备 NapCat 镜像并重启服务；保留 `data/` 与 `runtime/`。
- **更快的启动/停止**：一键启动和 NapCat 启动不再阻塞等待扫码；全部停止会按 Koishi → NapCat 的顺序快速退出。
- **人设 v2**：`[NAME LOAD]` 与 `[SETTING LOAD]` 拆成独立卡片，设定改为严格条目列表；面板支持独立编辑和专用保存路由。
- **提示词引擎重构**：section 与 stage plan 由 JSON 配置驱动，支持热更新；移除硬编码提示词和旧 AI Chat 模块。
- **群聊循环移除自定义 ReAct/工具栈**：改为 DSH 原生流程，删除重复的解析、预算和工具实现。
- **概览卡片收敛**：NapCat/Koishi 卡片更紧凑；运行环境安装卡片不再出现在概览页。

## Fixes

- 修复一键启动等待二维码导致长时间无响应的问题。
- 修复 `qqbot_status` 中 DSH agent model 显示不正确。
- 修复旧角色设定、NAME/SETTING 保存和提示词预览不一致。

## Requirements

- macOS Apple Silicon only
- DSH `>=0.2.1-rc.2 <0.3.0`
- Node.js `^22.19.0 || >=24.0.0`
- OrbStack 已安装并完成首次初始化（插件会自动启动它，但不会自动安装）
- 可访问 GitHub Release（首次启动下载约 594 MB 的 NapCat 镜像包）
- 首次使用手机扫码登录机器人 QQ

本版本不再要求本机 `QQ.app` 或管理员授权。

## Upgrade Notes

- 安装新插件后重启 DSH，确保加载新的路由和 Docker 后端代码。
- 第一次启动 NapCat 会下载约 594 MB 镜像包；之后复用本地镜像。
- Docker NapCat 使用独立数据目录，旧的本机 QQ/NapCat 注入配置不再使用。
- 机器人账号需要重新扫码登录；普通 QQ 登录不受影响。
- 升级不会删除 Koishi 的 `data/` 或 NapCat 的 `runtime/`；首次启动会创建 Docker 运行时目录。
